이미 쓰고 있다면: 트레이(맥은 메뉴 막대)의 고양이 아이콘에서 CCS 종료를 누른 뒤, 새로 받아 덮어 설치하세요. 설정은 그대로 남아요.

시작하기 전에

  1. Claude Code에 로그인되어 있어야 해요. 터미널에서 claude를 한 번 실행해 로그인해 두세요.
  2. Claude Pro 또는 Max 구독 계정이 필요해요.

Windows에 설치하기

  1. CCS-Setup.exe를 실행하면 바로 설치되고 바탕화면에 바로가기가 생겨요.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러 주세요. 서명 없이 친구들끼리 나누는 앱이라 처음 한 번 뜹니다.
  3. 화면 오른쪽 아래에 고양이가 나타나면 끝. 고양이에 마우스를 올리면 사용량이 보여요.

macOS에 설치하기

  1. CCS-mac.dmg를 열고 CCS를 응용 프로그램 폴더로 끌어다 놓으세요.
  2. 처음 열 때는 CCS를 우클릭 → 열기를 한 번 해 주세요.
  3. "키체인 접근 허용" 창이 뜨면 허용을 눌러 주세요. Claude Code 로그인 정보를 읽기만 합니다.

그래도 "손상되었기 때문에 열 수 없습니다"라고 나오면 터미널에서 xattr -cr /Applications/CCS.app을 실행한 뒤 다시 열어 주세요.
